# AlphaZero Gomoku (五子棋 AI 与图形界面)

一个基于 **AlphaZero 算法架构**（蒙特卡洛树搜索 MCTS + 策略价值网络 Policy-Value Network）的五子棋程序，内置完整的原生桌面图形界面（GUI）与终端对战模式（CLI），可直接在本机运行并与 AI 进行实战对弈。

---

## ✨ 核心特性

1. **AlphaZero 核心架构实现**
   - **MCTS 蒙特卡洛树搜索**：采用 PUCT 上置信界算法进行平衡探索与利用，支持自对弈时狄利克雷噪声（Dirichlet Noise）注入以保证开局多样性，支持子树重用。
   - **双策略价值评估引擎**：
     - **即开即用启发式策略价值评估器（Heuristic Policy-Value Evaluator）**：纯 Python 实现，零第三方库依赖，内置五子棋战术特征（活四、冲四、活三、嵌五等）评分系统与 Softmax 概率分布映射。**无需漫长训练，开箱即具备极高棋力！**
     - **PyTorch 深度残差策略价值网络（ResNet Policy-Value Net）**：标准 AlphaZero 双头网络结构，支持自对弈数据收集、8 种旋转翻转对称增强与自监督训练。
   - **候选点剪枝加速（Candidate Pruning）**：根据现有棋子邻域距离智能过滤无效点，将 15×15 棋盘的推演分支从 225 个大幅缩减至高价值区域，大幅提升搜索深度与响应速度。

2. **精美的原生桌面图形界面（GUI）**
   - **高清木质棋盘**：真实木纹色泽、天元与星位标记、标准代数坐标（A-O, 1-15）。
   - **3D 立体质感棋子**：拟真高光微反光与落子阴影，黑白子质感细腻。
   - **实时胜率条（KataGo / AlphaGo 风格）**：根据 MCTS 根节点估值动态显示黑白双方胜率百分比。
   - **多线程推演**：AI 思考在后台线程独立运行，界面丝滑无卡顿，带思考动画提示。
   - **全套辅助功能**：
     - 🔄 **新对局**：一键重开。
     - ↩️ **悔棋**：自动回退人类与 AI 步骤。
     - 💡 **AI 支招（推荐落点）**：在棋盘上标记前 3 名最佳候选点及预估胜率。
     - 🤖 **AI 自对弈演示**：观看 AlphaZero 左右互搏，学习战术走法。
     - 🔢 **显示手数序号**：在棋子上显示落子顺序编号。
     - 📐 **棋盘规格切换**：支持 15×15（标准五子棋）、11×11（快棋）、9×9（微棋盘）。
     - ♟️ **执黑（先手）/ 执白（后手）随时切换**。

## 🚀 快速启动

程序完全支持 macOS 原生环境，**无需安装任何额外依赖即可直接启动！**

### 1. 启动图形界面对战 (推荐)
打开终端并进入项目目录：
```bash
cd ~/dev/gomoku_gemini
python3 main.py
```
这会立即弹出图形对战窗口，点击棋盘交叉点即可开始与 AlphaZero 对弈！

### 2. 启动终端命令行模式
如果你希望在纯命令行窗口下体验：
```bash
python3 main.py --cli
```
在提示时输入代数坐标（例如 `H8`、`G7`）即可落子。

## 🧠 目录结构与技术实现

```text
gomoku_gemini/
├── board.py              # 棋盘规则、状态表示、连五胜负判定、特征平面提取
├── tactics.py            # 五子棋战术启发式评估与局部形状分析（活四、冲四、活三等）
├── mcts.py               # AlphaZero PUCT 蒙特卡洛树搜索与节点管理
├── policy_value_net.py   # 策略价值网络（启发式网络 + PyTorch 深度残差网络）
├── train.py              # AlphaZero 自对弈数据采集与强化学习训练管线
├── evaluate.py           # 模型对抗评测脚本（AI 自对弈对决）
├── battle_vs_b200.py     # 对抗基线引擎实战评测
├── plot_loss.py          # 训练 Loss 与走子步数曲线可视化绘图
├── gui.py                # Tkinter 桌面图形界面（木质棋盘、3D立体棋子、胜率条、多线程）
├── play_cli.py           # 命令行终端对弈模式
├── main.py               # 统一启动入口
└── models/               # 训练模型权重存放目录 (包含 v1 与 v2 权重)
```

### 状态特征平面 (State Feature Planes)
神经网络输入为 `[4, H, W]` 张量：
- **Plane 0**：当前玩家现有棋子分布 (1.0 / 0.0)
- **Plane 1**：对手现有棋子分布 (1.0 / 0.0)
- **Plane 2**：最后一手落子位置指示
- **Plane 3**：当前行动方颜色标量平面（黑方全 1.0，白方全 0.0）

## 🏋️ 训练自己的 PyTorch AlphaZero 模型（可选）

如果你想尝试从零进行真正的深度强化学习自对弈训练：

1. 安装 PyTorch：
   ```bash
   pip install torch
   ```
2. 运行自对弈训练管线（建议先在 9×9 棋盘上快速验证）：
   ```bash
   python3 train.py --board_size 9 --iterations 50 --playouts 200
   ```
3. 训练生成的模型权重将自动保存在 `models/` 目录下，启动 GUI 时可直接在“AI引擎”下拉菜单中选择“PyTorch深度残差网络”进行对战。
